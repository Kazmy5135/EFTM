# 《逃离塔科夫》格子库存“华容道”研究

## 研究问题

玩家所说的“逃离塔科夫华容道”具体是什么，以及 EFTM 在手机竖屏、单手操作条件下应该保留哪部分体验。

## 术语结论

“华容道”不是《逃离塔科夫》的正式系统名，而是中文玩家对其格子库存整理的俗称，也常被称作“背包俄罗斯方块”或 inventory tetris。

其基础规则是：容器具有二维格子布局；不同物品占据不同宽高的矩形空间；玩家需要在有限空间中放置和重新排列物品。背包、胸挂、口袋、保险箱和局外仓库拥有不同布局，一些容器的内部容量还可能大于自身占用空间。

## 真正构成体验的部分

1. **物品不是抽象容量数字。** 枪械、护甲、弹匣、食物和杂物以不同尺寸直接占据空间，形状本身参与价值判断。
2. **连续空格比总空格更重要。** 即使剩余格数足够，空间形状不合适也可能装不下新物品。
3. **整理本身产生选择。** 玩家需要腾挪、旋转、丢弃或替换物品，比较单位格价值、即时用途、任务用途和稀有度。
4. **搜索发生在风险中。** 局内搜刮会占用时间；死亡又会丢失绝大多数携带物，因此“再整理一下”本身就是风险决策。
5. **获得感来自成功塞入战利品。** 找到高价值大件后，通过整理挤出空间，是搜刮体验的一部分，而不仅是 UI 管理负担。

## 对 EFTM 的设计推论

EFTM 应复现“空间形状 + 物品价值 + 暴露时间”的三角取舍，而不是照搬 PC 鼠标操作：

- 保留物品占格、有限连续空间、取舍与整理收益。
- 搜索与整理期间，地图时间和危险继续存在。
- 竖屏布局必须让主要库存区域位于单手拇指可操作范围。
- 不应要求像素级拖放；拿起、落位、旋转、交换和退回都需要明确容错。
- 高频操作应能由一根拇指连续完成，第二只手只能作为可选加速方式。
- 自动整理可以处理低价值重复劳动，但不能消灭“为了关键战利品做空间取舍”的核心决策。

以上是研究推论，不是已经批准的交互方案。具体手势、格子尺寸和界面布局需要通过手机原型验证。

## V1 建议验证指标

- 单手完成拿取、移动、旋转、替换和丢弃的成功率与误触率。
- 从发现目标物到成功装入背包的用时。
- 玩家是否能在不阅读说明的情况下理解“为什么装不下”。
- 整理期间遭遇危险时，玩家能否立即退出或恢复地图状态。
- 自动整理功能是否保留了高价值物品的空间决策。
