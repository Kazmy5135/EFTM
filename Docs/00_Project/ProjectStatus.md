# 当前项目状态

- 当前阶段：产品定义与核心战斗设计讨论中；正在把掩体枪战转译为竖屏单手交互。
- Unity 基线：`2022.3.62f2`。
- 仓库布局：`Docs/`、按需启用的 `H5Prototype/` 与正式 `UnityProject/` 三个平级工作区；H5 不属于通用开发门禁。
- 已建立：运行时、编辑器、EditMode 测试程序集，启动与服务生命周期骨架，文档治理框架。
- 已初步确定：手机竖屏、单手为主、多人实时搜打撤；核心交互由剪刀石头布式半回合枪战（自动瞄准、手动按住连续开火）和单手格子背包搜索构成；V1 使用机器人 PMC 验证核心体验。
- 已初步确定：核心战斗采用第三人称通道场景，敌人位于尽头掩体且隐藏时不可见，玩家在近端左右掩体间行动；玩家从左侧掩体向右滑、从右侧掩体向左滑，以 600ms 横穿切换掩体，期间每发被命中概率固定 20%；上滑触发 300ms 歪头探身架枪，完成后出现中央按住连续开火键，下滑主动回掩体。弹匣和换弹键位于右下角；弹匣未满时可在掩体内安全换弹，也可在完成架枪后保持 100% 暴露换弹。双方使用 15 发弹匣，空弹保持架枪并触发高优先级警报；未命中显示 `MISS`，受伤显示掉血数值；手机设计基准为 1080×2160 竖屏。
- 尚未决定：完整战斗时序、敌方隐藏后的情报反馈、手雷与复杂换位输入、探索移动方式、格子背包手势、正式多人形态、渲染管线和内容管线。
- 验证状态：上一版 `H5-COMBAT-001` 已由 Git commit `de45dd2` 保存并停止作为当前原型；新工作项 `004-peek-camera` 的 `H5-PEEK-CAMERA-001` 已完成 11 项自动化、默认遮挡/完全探出视觉对比、540×1080 与 1080×2160 页面检查及局域网 HTTP 验证，等待设计者手机实机判断按住/松开、侧倾和视差体感。该原型不包含战斗、敌人、弹匣或换弹。迁移前 Unity 2022.3.62f2 导入成功、框架校验通过、3 个 EditMode 测试全部通过，迁移后的 Editor 校验与测试待在同版本 Unity 下复验。
- 当前阻塞：无。
- 下一门禁：完成 `H5-PEEK-CAMERA-001` 的目标视口验证后，由设计者在同局域网手机上判断默认遮挡、按住探出、侧倾幅度、空间视差与松开缩回是否自然；确认视角后再恢复敌人和其他战斗系统的设计验证。
