# 当前项目状态

- 当前阶段：战斗模块 V1 的设计、H5 验证和 Unity 技术基线均已批准；正式 Unity 开发从 U1 确定性领域模型开始。
- Unity 基线：`2022.3.62f2`。
- 仓库布局：`Docs/`、按需启用的 `H5Prototype/` 与正式 `UnityProject/` 三个平级工作区；H5 不属于通用开发门禁。
- 已建立：运行时、编辑器、EditMode 测试程序集，启动与服务生命周期骨架，文档治理框架。
- 已初步确定：手机竖屏、单手为主、多人实时搜打撤；核心交互由剪刀石头布式半回合枪战（情报辅助预瞄、有限手动调瞄和压枪、按住连续开火）与单手格子背包搜索构成；首个完整 Demo 使用机器人 PMC 验证核心体验。
- 战斗模块 V1 基础方向：第三人称固定通道和真实掩体遮挡；左侧点击真架枪、再次点击返回，右侧按住假动作、松开返回，不再使用上滑架枪或下滑回撤。假 Peek 看到至少 10% 敌人轮廓后记录旧位置；完全缩回后显示黄色透视剪影，敌人有 25% 概率在五个点位间换位。下一次真架枪一次性预瞄旧位置，玩家可在中央画面或开火键上拖动调瞄、压枪；开火可提前预备，但完全探出后才发射。
- V1 边界：当前只确认真假 Peek、位置情报、辅助预瞄、有限枪械控制和基础射击手感，不代表完整战斗系统或完整游戏。弹匣、伤害、换弹、左右掩体、手雷、敌人 AI、多人同步、探索、搜索、撤离和局外成长仍需后续设计与验证。
- 尚未决定：真架枪中途取消、后续参数调优、后续战斗模块顺序、探索移动方式、格子背包手势、正式多人形态、渲染管线和内容管线。
- 验证状态：`H5-PEEK-CAMERA-001 V1` 已完成 24 项自动化、目标视口、浏览器和局域网验证。设计者于 2026-09-03 确认全部通过，并批准 `DESIGN-PRODUCT-DEFINITION`、`DESIGN-CORE-COMBAT` 与 `DDR-001` 为 accepted。旧版 `H5-COMBAT-001` 仅由 Git commit `de45dd2` 保留。Unity 2022.3.62f2 框架此前通过 3 个 EditMode 测试，尚未实现本战斗 V1。
- 当前阻塞：当前主机未安装项目要求的 Unity 2022.3.62f2；只发现 2019.4.8f1 和 6000.0.73f1。U1 纯 C# 草案已通过独立 NUnit 16/16，但不能用错误版本生成 `.meta` 或替代正式 Unity Test Runner 结论。
- 下一门禁：使用 Unity 2022.3.62f2 导入 U1 文件并生成 `.meta`，通过 Unity 编译、现有 3 项与新增 16 项 EditMode 测试后，才能提交 U1 并进入 U2 场景、输入和摄像机。弹匣、伤害、换弹、手雷和敌人 AI 继续作为后续独立模块推进。
