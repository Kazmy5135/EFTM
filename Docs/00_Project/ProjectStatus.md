# 当前项目状态

- 当前阶段：产品定义与核心战斗设计讨论中；正在把掩体枪战转译为竖屏单手交互。
- Unity 基线：`2022.3.62f2`。
- 仓库布局：`Docs/`、按需启用的 `H5Prototype/` 与正式 `UnityProject/` 三个平级工作区；H5 不属于通用开发门禁。
- 已建立：运行时、编辑器、EditMode 测试程序集，启动与服务生命周期骨架，文档治理框架。
- 已初步确定：手机竖屏、单手为主、多人实时搜打撤；核心交互由剪刀石头布式半回合自动枪战和单手格子背包搜索构成；V1 使用机器人 PMC 验证核心体验。
- 已初步确定：核心战斗采用第三人称、双方固定掩体和单一枪线；以按住探身架枪、自动开火、松开回掩体为基本输入；探身总时长 300ms，前 150ms 命中概率为 0%，后 150ms 从 30% 升至 100%；双方使用相同战斗参数与 15 发弹匣，打空后保持架枪但不能攻击；底部为左空位、中探身、右换弹三栏，完全位于掩体内且弹匣未满时点击右侧一次触发 2 秒自动换弹；未命中显示 `MISS`，受伤显示掉血数值；手机设计基准为 1080×2160 竖屏。
- 尚未决定：具体战斗时序、情报反馈、手雷与换位输入、探索移动方式、格子背包手势、正式多人形态、渲染管线和内容管线。
- 验证状态：`H5-COMBAT-001` 已完成实现、20 项自动化检查、双方参数对称、掩体内单次触发换弹、空弹高优先级警报、三栏布局、iOS 长按/缩放抑制、局域网 HTTP 检查及 1080×2160 / 540×1080 视口检查，等待设计者通过同局域网手机复验；迁移前 Unity 2022.3.62f2 导入成功、框架校验通过、3 个 EditMode 测试全部通过，迁移后的 Editor 校验与测试待在同版本 Unity 下复验。
- 当前阻塞：无。
- 下一门禁：设计者在同局域网手机上试玩 `H5-COMBAT-001`，反馈 300ms 探身曲线、空弹警报强度、三栏按钮可达性、右侧单次触发 2 秒换弹与战斗蹦字体感，再决定战斗时序。
