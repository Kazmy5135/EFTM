# 003 - 核心掩体战斗设计

## 问题与背景

产品已经确定以半回合制自动瞄准与手动按住连续开火替代手机上的准星移动和压枪，但“剪刀石头布”不能停留在抽象描述。需要把《逃离塔科夫》中探身、干拉、架枪、换位和投雷的高频博弈转译为竖屏单手可操作的战斗规则。

## 目标和预期结果

- 定义上滑架枪、按住连续开火、下滑回掩体和横向切换掩体的核心输入。
- 定义架枪先手、干拉风险、手雷破点和换位重置的克制关系。
- 定义战斗状态、可观察反馈、异常路径和验收方式。
- 收敛为一个玩家对机器人 PMC 的最小战斗原型。

## 范围

- 有效掩体之间的中短距离枪战。
- 第三人称、通道尽头敌方掩体、玩家近端左右掩体和单一枪线的首个交互切片。
- 探身、架枪、连续开火、回掩体、投雷和左右换位。
- 竖屏单手完成核心循环。
- 多个短博弈循环组成一次交战。
- 设计基准为 1080×2160 的手机竖屏单指输入。

## 非目标

- 本工作项不完成全套武器、弹药、伤势和护甲系统。
- 不决定网络同步与反作弊方案。
- 不覆盖所有无掩体和极近距离战斗。
- 不制作最终美术和完整 UI。

## 下游影响

- 角色动作与掩体系统。
- 自动瞄准、手动按住连续射击和命中结算。
- 敌人战斗 AI。
- 投掷物与换位系统。
- 战斗 UI、音画反馈和手机输入。

## 初始验收案例

- 玩家只用一只手上滑即可架枪，完成后可按住连续开火或下滑回到掩体。
- 玩家可以在近端左右掩体间切换，移动期间每发被命中概率固定为 20%。
- 敌人退入通道尽头掩体后不可见。
- 先架枪者对后续干拉者具有清晰优势。
- 掩体内不能攻击，也不会被普通直射枪火命中。
- 已知敌方架枪时，手雷或换位能够提供破局路径。
- 一次交战自然包含多个判断循环。

## 待决策

- 手势区域、中央开火键、右下换弹键、架枪/开火/切换时序参数与命中优势的表达方式。
- 对手状态的情报反馈。
- 手雷、换位和趴下的单手输入。
- 手雷对掩体内目标的具体威胁规则。
- 多目标、同时探身和近距离交战规则。
