# 004 - 3D 摄像机 Peek 视角验证

## 问题与背景

上一版 H5 同时实现战斗、弹匣、换弹、切换掩体与反馈，已经不适合作为摄像机 Peek 体感实验。设计者要求废弃该当前实现，在 Git 保留历史，并用同一手机 H5 运行架构重做真 3D 原型；在基础视角确认后，本轮增加真架枪、假动作和准星射击的最小交互对照，不恢复完整战斗系统。

## 验证假设

玩家默认位于通道入口右侧的近墙后，主体视野被真实几何遮挡，但左侧边缘可以预先看到少量通道。左侧“真架枪”点击后自动完成并锁定 Peek，完全探出后出现可用的开火键；右侧“假动作”只在按住期间 Peek，松开立即缩回且不能开火。该对照应让玩家能区分承诺暴露的攻击动作和可随时取消的试探动作。

## 范围

- 1080×2160 手机竖屏与单指输入。
- 一处固定右侧近墙掩体。
- 一个具有明显纵深、灯光、结构重复和近远参照物的真 3D 工业通道。
- 点击锁定的真架枪、按住/松开的假动作及共同的摄像机 Peek 表现。
- 真架枪开始后中央圆形开火键立即可按住预备；完全探出后以约 108ms 间隔按屏幕准星方向连续射击。第 1 发正常起跳，第 2～4 发逐发增强，第 5 发起角色自动稳枪，垂直冲量降低且回正加快；随机水平偏移贯穿全程。按住手指可拖动镜头，初段需要明显下压，稳定后需要减小下压，松开立即停火并重置下一轮连射阶段。
- 通道内五个随机候选点位的假人目标；露出档位覆盖头部、肩部、上半身和全身。
- 假动作期间以真实遮挡后的轮廓采样判断可见比例；达到 10% 时记录当次旧位置为预瞄情报。
- 任意 Peek 完全缩回后，敌人以 25% 概率换到另外四个点位之一；换位不覆盖已经记录的旧位置。
- 取得预瞄情报并完全缩回后，在旧位置显示黄色发光透视剪影；下一次真架枪或假 Peek 开始时消失，重新取得情报后更新位置。
- 真架枪仅消费新取得的预瞄情报并一次性吸附到旧位置；没有新情报时保留上次手动调整后的准星。
- 真架枪状态下，除三个操作键以外的中央画面支持单指拖动调瞄。
- 同局域网手机访问。

## 非目标

- 不包含敌人 AI、生命、伤害、弹匣、换弹、切换掩体或联网对战。
- 不验证武器模型、角色身体、战斗数值与真人对抗。
- 不决定正式 Unity 摄像机实现、动画方案或生产美术标准。
- 本实验可以在设计者确认后同步为 draft 设计方向，但不能自动成为 accepted 基线或 Unity 技术契约。

## 技术实验选择

- 使用 Three.js WebGL 构建真 3D 几何体，验证遮挡、横移、侧倾和视差。
- Three.js 作为本地 npm 依赖，由原有 Node 静态服务器映射给局域网设备，不依赖外部 CDN。
- 300ms 探出、240ms 缩回、约 7° 侧倾是本轮实验参数，不是正式技术契约。

## 成功判据

- 默认状态主体视野为近处遮挡面，但左侧边缘能看到一条通道，且不能获得完整通道情报。
- 点击真架枪后摄像机自动连续探到底并锁定，开火键出现；再次点击真架枪后返回掩体。
- 按住假动作后连续探出，松开立即返回，并在 240ms 实验时长内恢复掩体状态；假动作期间不显示开火键。
- 假动作中敌人实际可见轮廓达到 10% 后，信息栏显示“已预瞄”；未达到阈值或从未观察到敌人时显示“没有敌人信息”。
- 完全回掩体后敌人每轮以 25% 概率换位；下一次真架枪仍吸附到假动作最后观察到的旧位置，形成情报过期风险。
- 掩体后黄色透视剪影应稳定标示最后观察位置，开始下一次 Peek 时立即消失；若假 Peek 再次跨过阈值，缩回后在新观察位置重新出现。
- 真架枪结束后直接再次真架枪时保留上次准星；只有重新假 Peek 并跨过 10% 阈值，下一次真架枪才重新吸附。
- 真架枪后拖动中央画面可以连续调整准星，开火、真架枪与假动作按钮的输入优先级不受影响。
- 真架枪按下后开火键立即可按住预备，但探身完成前不产生射线；完全探出后连续发射，松开立即停火。
- 提前按住开火时，Peek 完成帧只更新并渲染摄像机，预备的第一发在紧随其后的帧结算，不出现可感知的单帧卡顿。
- 按住开火键上下左右拖动时镜头跟随；第 2～4 发形成明显爬升，第 5 发起自动稳定，持续使用同一向下幅度会压过目标；随机左右偏移不能完全预判，射线能够命中尽头只露头的固定假人并给出反馈。
- 中途松开或返回途中再次按住不会跳变、卡死或反向错乱。
- 目标竖屏无滚动、浏览器缩放或 iOS 长按选择干扰。
- 页面不包含上一版弹匣、换弹、生命、伤害与切换掩体状态。

## 失败与停止判据

- 未按住时能看到过多通道内部，失去主动 Peek 的信息增益。
- Peek 只表现为 UI 变形或平面移动，缺乏可感知空间视差。
- 假动作松开后仍停留在暴露视角，或快速重按导致摄像机瞬移。
- 真架枪没有锁定、假动作能够开火，或射击方向与准星不一致。
- 真架枪后立即按住开火，在 Peek 完成和首发衔接处出现明显停顿或输入卡死。
- 目标手机无法稳定运行 WebGL 场景。

## V1 设计回传

- 设计者于 2026-09-02 确认取消原先上滑架枪和下滑回撤，把当前 H5 方向作为战斗模块 V1 的最基础方向。
- `H5-PEEK-CAMERA-001 V1` 只覆盖真假 Peek、旧位置情报、辅助预瞄、有限调瞄和基础射击手感，不代表完整战斗系统或完整游戏。
- 回传目标 `DESIGN-PRODUCT-DEFINITION`、`DESIGN-CORE-COMBAT` 和 `DDR-001` 已于 2026-09-03 由设计者全部批准为 accepted。
- 设计确认后的下一流程为 Unity 技术设计，再拆分最小 Unity 实现与验证；不直接把 H5 的 Three.js 结构迁入 Unity。
