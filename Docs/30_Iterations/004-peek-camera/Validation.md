## 观察到的行为

- 初版默认视角中，摄像机紧贴右侧入口近墙，画面只呈现墙面。设计者于 2026-09-02 要求摄像机后退，使左侧边缘能够看到少量通道；当前默认构图中，主体仍由墙遮挡，左侧保留一条暗通道和入口地面引导线。
- 初版完全探出画面的侧倾方向与左 Peek 语义相反；当前已翻转摄像机 Roll，完全探出时通道和右侧墙边向相反方向倾斜，符合本轮指定的左 Peek 表现。
- `?debugPeek=1` 保持完全探出时，墙边退至画面右侧并形成约 7° 画面侧倾；通道顶灯、地面分段、左右墙、箱体和远端结构同时进入视野，能够读出纵深与视差。
- 完全探出时状态显示“完全探出 · 通道可见”，准星和 Peek 进度出现；默认状态显示“掩体后 · 通道边缘可见”。
- 说明卡随 Peek 进度淡出，不遮挡完全探出后的通道观察区域。
- 设计者于 2026-09-02 将单一 Peek 扩展为两种操作：左侧“真架枪”点击后自动探到底并锁定，再次点击缩回；右侧“假动作”保持按住探出、松开缩回。假动作期间不提供开火。
- 真架枪开始后中央大圆形 `FIRE` 立即出现且可按住；探身完成前只进入预备状态，完全探出后以约 108ms 间隔从屏幕中央准星连续发出射线，松开、失焦或切后台立即停火。分段曲线以 `0.018rad` 为基础垂直冲量：第 1～4 发乘数依次为 `1 / 1.35 / 1.65 / 1.9`，第 5 发起降为 `0.52`；回正时长由爬升段 `250ms` 加快到稳定段 `145ms`。水平基础冲量为 `0.012rad`，每发随机正负方向，稳定段保持 1.15 倍水平不确定性；累计垂直和水平偏移分别限制在 `0.09rad` 与 `±0.045rad`。松手后发数归零，下次连射重新经历起跳段。
- 假人改为五个候选点位，并以 20 个身体采样点结合摄像机视锥与真实 3D 遮挡计算可见轮廓。完全探出时五个位置的实测可见比例依次约为 `15% / 35% / 65% / 65% / 100%`，覆盖只露头至全身；任一位置都可跨过本轮 `10%` 情报阈值。
- 假动作跨过阈值时记录当前旧位置并显示“已预瞄”；每次任意 Peek 完全缩回后，假人有 `25%` 概率移动到另外四个位置之一。换位不改写旧情报，下一次真架枪只消费新情报并一次性吸附；没有新假 Peek 情报时，再次真架枪保留上一次手动准星。
- 取得情报并完全缩回后，旧位置显示黄色填充加发光线框组成的透视剪影；材质关闭深度测试，因此近墙不会遮住情报标记。开始下一次真架枪或假 Peek 时剪影隐藏；重新跨过阈值后，下一次缩回时更新。
- 真架枪状态下，中央非按钮区域支持单指拖动调瞄；开火、真架枪与假动作按钮保持独立输入层。
- 环境背景、墙地材质、色调曝光、环境光、入口光与远端光已整体提高，画面暗角降低；默认掩体面和完全探出后的通道结构均可辨识。
- 页面不存在弹匣、换弹、生命、伤害与切换掩体控件。
- WebGL 可用时使用 Three.js 真 3D；无法创建 WebGL 上下文时使用同状态驱动的 Canvas 2D 降级画面，避免黑屏，但降级画面不能作为真 3D 视差结论。

## Agent 推论

- 真 3D 近墙遮挡比上一版角色平移动画更直接地解释“为什么主动探头能获得更多通道情报”；默认保留少量边缘视野，避免初始画面退化为单色墙面。
- 当前完全探出构图仍保留右侧墙边，能持续提示玩家自己依附在掩体边缘；多档位敌人可用于验证“有限情报—预瞄旧点—目标可能换位”的判断循环。
- 自动浏览器不能保持真实手指长按，因此按住时序由状态模型和事件契约验证，视觉终点由调试参数验证；长按肌肉反馈仍必须由手机实机补充。

## 当前结论

- 2026-09-02 当前修订已满足“10% 真实轮廓获取情报、五档敌人露出、25% 隐蔽换位、旧位置黄色透视剪影、旧位置一次性预瞄、无新情报时保留手动准星、中央拖动调瞄”的自动化和浏览器判据，同时保留既有视角与射击体验。阈值、剪影强度与过期预瞄是否形成合适博弈，以及手机拖动手感仍等待设计者实机验收；该结果不表示 `DESIGN-CORE-COMBAT` 已批准，也不形成 Unity 技术契约。
