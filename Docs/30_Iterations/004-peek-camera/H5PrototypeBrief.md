# H5-PEEK-CAMERA-001

## 设计来源及状态

- 来源：设计者于 2026-09-01 提出的参考图与交互说明。
- 相关设计：`DESIGN-CORE-COMBAT`，draft；本实验不直接修改其正式语义。
- 旧实验：`H5-COMBAT-001` 已由 Git commit `de45dd2` 保存，本轮不继承其实现范围。

## 目标体验与假设

默认摄像机真正藏在近墙后，玩家看不到通道。按住 `PEEK` 后摄像机像人歪头探身一样横移和侧倾，让通道从墙边逐渐显露；松开后立刻缩回。玩家应从真实遮挡和空间视差，而非角色动画或文字提示，理解暴露与观察的关系。

## 原型范围

- 真 3D 固定工业通道。
- 单个固定右侧掩体与一台透视摄像机。
- 按住、保持、松开的单输入循环。
- 300ms 探出、240ms 缩回与约 7° 侧倾占位参数。
- 1080×2160 手机竖屏和同局域网访问。

## 非目标

- 敌人、枪械、瞄准、射击、伤害、弹匣、换弹、左右掩体和战斗 AI。
- 正式数值、Unity 实现、最终材质、模型与性能结论。

## 验收步骤

1. 用手机竖屏进入默认页面，确认只能看到近处遮挡面。
2. 按住底部 `PEEK`，观察通道是否连续显露并产生侧倾与视差。
3. 保持按住，确认视角稳定在完全探出状态。
4. 松开，确认立即开始缩回并恢复完全遮挡。
5. 在探出中途松开，并在返回中途再次按住，确认运动连续。
6. 重复至少十轮，观察卡死、页面滚动、系统手势和性能问题。

## 期望证据

- 摄像机状态自动化测试。
- 默认隐藏与完全探出两种目标视口截图。
- 1080×2160 和 540×1080 页面几何检查。
- 浏览器错误日志、局域网 HTTP 检查和设计者手机反馈。
