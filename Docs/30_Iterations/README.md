# 工作项与变更记录

本目录保存工作过程，不作为当前设计或技术基线。

## 工作类型

- `new-design`：建立新设计规格。
- `design-change`：修改 accepted 设计规格。
- `new-technical`：建立新技术规格。
- `technical-change`：修改 accepted 技术规格。
- `development`：实现已批准的设计和技术契约。
- `validation`：执行验证或一致性验收。
- `governance-change`：修改项目治理规则。

## 使用方式

1. 明确目标、范围、非目标、负责人和验收方式。
2. 复制 `_template` 为 `###-short-name`。
3. 工作过程中维护任务和验证证据。
4. 收口时记录实际结果、生效 commit、遗留项和下一个门禁。
