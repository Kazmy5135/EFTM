# 核心战斗设计

## 文档目标

定义 EFTM 如何在手机竖屏上用低输入负担还原掩体枪战中的观察、试探、架枪、预瞄、开火和情报过期博弈。本文件描述玩家可观察规则，不决定 Unity 代码结构、网络同步方式或最终美术表现。

## V1 定位与边界

本文所称 `战斗模块 V1`，只代表核心战斗最基础方向，不等于完整战斗系统，也不等于完整游戏或首个完整可玩 Demo。

战斗模块 V1 当前只确认下列基础问题：

- 玩家如何在掩体后观察、假 Peek 和真架枪。
- 不复刻移动端 FPS 全套双摇杆瞄准的前提下，如何保留预瞄、有限调瞄和压枪参与感。
- 敌人位置情报如何获取、显示、过期并影响下一次架枪。
- 完全探出后如何按住连续开火，以及后坐力如何形成可控制的短循环。

2026-09-08，工作项 008 的双侧掩体换边与移动情报获取已获设计批准，作为 V1 基础方向上的首个扩展纳入本文；原 H5 V1 与 Unity 单侧实现仍是历史基线，不表示已实现或验证换边。

弹匣、换弹、伤害、护甲、手雷、敌人 AI、多人同步和完整战术集合仍属于后续战斗设计，不因本次扩展被视为已经确认。

## 范围

### V1 包含

- `1080 × 2160` 手机竖屏和单手为主的输入。
- 第三人称固定通道、左右两处玩家近端石板掩体和一条主要枪线。
- 两个固定玩家点位之间面朝通道的真实横移换边及移动情报获取；到达后不自动 Peek。
- “真架枪”与“假动作”两种不同承诺程度的 Peek。
- 真实几何遮挡、敌人可见轮廓识别和最后观察位置情报。
- 旧位置自动预瞄、有限手动调瞄、按住连续开火和分阶段后坐力。
- 五个离散敌人候选位置和完全隐藏后的概率换位。

### V1 不包含

- 完整生命、伤害、弹匣、换弹、护甲、伤势和穿透规则。
- 自由行走、多点自由寻路、手雷、趴下、卡壳或治疗。
- 敌人决策 AI、真人对抗、多人网络同步和延迟补偿。
- 多目标、近距离无掩体遭遇、室内突入或复杂射角。
- 正式武器模型、角色动画、材质、特效和性能结论。

## 核心体验原则

1. **先获取情报，再决定是否承诺攻击。** 假动作提供可撤回的观察，真架枪承担完整暴露和攻击承诺。
2. **预瞄有价值但不保证正确。** 系统帮助玩家瞄向最后观察位置，但目标可能已经换位。
3. **输入简单，结果仍可被玩家影响。** 玩家不需要完整 FPS 瞄准操作，但可以有限调瞄和压枪。
4. **掩体保护必须由空间关系解释。** 玩家缩回后看不到真实敌人，Peek 获得的信息增益来自真实遮挡变化。
5. **情报反馈不等于实时透视。** 黄色剪影只表示最后观察位置，不能跟踪已经移动的敌人。

## 视角与战场约束

- 游戏采用第三人称视角，摄像机默认位于玩家掩体后方。
- 默认画面主体被近墙遮挡，但边缘保留少量通道，避免初始视图退化为单色墙面。
- Peek 时摄像机横向探出并产生符合方向的轻微侧倾，以真实视差逐渐露出通道。
- 左右以面向通道尽头为准：初始在右侧石板后，向左 Peek；左侧石板后向右 Peek。两侧使用各自石板的内侧边缘，中央留出真实可穿行空间。
- 战斗模块 V1 只验证一条主要枪线，不要求玩家选择多个射击方向。
- 敌人从真实几何后完全隐藏时，其真实角色不可见；黄色情报剪影不属于真实角色可见性。
- H5 V1 使用约 `300ms` 探出、`240ms` 缩回和约 `7°` 侧倾作为 V1 初始参数；后续调整必须经过设计变更流程。

## 单手核心输入

原先“上滑架枪、下滑回撤”的方案不再属于现行 V1 方向。

### 左侧：真架枪

- 玩家点击左侧“真架枪”后，角色自动持续 Peek 到完全探出并保持架枪。
- 真架枪是承诺动作，不要求玩家持续按住按钮维持。
- 再次点击真架枪后，角色停止攻击并返回掩体。
- 真架枪开始时，如果存在一次尚未消费的新假 Peek 或换边情报，准星立即预瞄到最后观察位置。
- 如果没有新情报，真架枪保留玩家上一次手动调整后的准星位置，不重复吸附。

### 右侧：假动作

- 玩家按住右侧“假动作”时持续 Peek，松开后立即开始返回掩体。
- 假动作可以探到完全暴露视角，但不能开火。
- 假动作的用途是观察、诱导和获取位置情报，不承诺进入攻击状态。
- 假动作与真架枪互斥；真架枪期间不能同时使用假动作。

### 中央：开火与调瞄

- 真架枪开始后，中央圆形开火键立即出现并可以按住。
- 摄像机完全探出前，按住开火只表示“预备发射”，不产生子弹或射线。
- 完全探出后，预备状态自动开始连续开火；直接在完全探出后按住也会立即开火。
- 松开开火键立即停止射击，但不自动结束架枪。
- 真架枪期间，除开火、真架枪、假动作和换边按钮以外的中央画面可以单指拖动，调整准星位置。
- 按住开火键的同一根手指也可以上下左右拖动镜头，用于跟枪和压枪。

### 第二只手

- 第二只手可以提供可选辅助，但不能成为完成 V1 基础循环的前提。
- 玩家必须能单手完成假 Peek、真架枪、预备开火、连续开火、调瞄、返回掩体和换边。

### 假动作上方：换边

- 在右下假动作键上方增加单次点击的换边键，文案随目的地显示“换到左侧 / 换到右侧”；信息栏显示所在侧或“换边中”。
- 只有完全隐藏时允许发起；真架枪、射击、假动作及返回过程中不可发起，提示“先回到掩体”。
- 换边是单次承诺：不需长按，连续点击不排队，中途不可取消或反向。
- 换边期间禁用真假 Peek、开火和拖动调瞄，不接受预备开火；完成落位后恢复。到达后不自动探头、不停留观察、不追加探出/缩回循环。

## 双侧换边、镜头与场景

- 右到左或左到右：点击后直接真实横移到另一侧石板后，移动全程保持面朝通道。取消起步前朝目标掩体转头，也不再执行回看动作。
- 移动位置与镜头连续变化，产生真实视差；不能只移动摄像机而让玩家空间位置留在出发点，不能瞬移、镜像画面或穿墙。
- 横移和抵达过程中，在实际视野达到阈值时记录情报；抵达目标隐藏位即结束移动观察，不为获取信息自动探出。
- 移动视线始终朝固定通道方向，不自动追踪或瞄准敌人，也不朝旧情报点转头；已保存的手动瞄准方向保留到后续真架枪。换边产生的视差不保证准星仍落在同一物体上。
- 失焦/暂停时释放指针和开火，暂停换边进度；恢复后继续移动到目标掩体，不瞬移或积累后台移动时间。
- 单次换边保留 0.80s 移动，其中最后 0.20s 为减速末段；删除原 0.15s 预转头后不额外等待。没有自动观察停留，普通 Peek 的 300ms/240ms 保持不变。此体验修订已由设计者确认，记录见 008/DirectSwitchRevision.md。
- 两侧隐藏位均遮住真实敌人且保留画面边缘通道；两侧探出后各自具有有效观察/攻击机会。五个敌人位置要从两侧分别验收，不要求左右暴露比例相同，但不允许某位置两侧均无法有效观察。
- 模型几何、双石板环境布局及关联道具调整必须在 Blender 源文件完成，导出后接入 Unity。Unity 只做导入、引用/场景接入、材质/碰撞和玩法配置验证，不复制拼接石板或修改网格代替 Blender 流程；空间问题返回 Blender 修正。
- 不新增玩家受击、20% 移动命中概率、无敌帧、敌人 AI 或完整移动系统。

## 情报、剪影与预瞄

### 情报获取

- 手动假动作期间，以及换边横移/抵达过程中，可以建立敌人位置情报；完全隐藏及普通真架枪不新增情报。
- 系统根据真实场景遮挡后的敌人可见轮廓判断，而不是仅根据敌人是否进入屏幕矩形。
- 当敌人可见轮廓达到或超过 `10%` 时，本轮假 Peek 或换边获得有效位置情报，记录最后实际所见；不因到达而额外延长观察窗口。
- 未达到阈值时不更新位置情报。
- 信息栏使用“已预瞄”和“没有敌人信息”告诉玩家当前是否存在可用的最后观察位置。

### 黄色透视剪影

- 假 Peek 获得有效情报并完全返回掩体后，或换边获得有效情报并完成隐藏落位后，在敌人最后观察位置显示一个黄色发光人形剪影。
- 剪影可以透过玩家近墙和场景遮挡显示，帮助玩家理解预瞄点在哪里。
- 剪影代表历史位置，不代表敌人仍在那里，也不跟随已经换位的敌人。
- 下一次真架枪、假动作或换边开始时，现有剪影立即消失。
- 如果新的假 Peek 再次达到 `10%` 阈值，完全缩回后在新的最后观察位置生成更新后的剪影。
- 如果新的 Peek 或换边没有重新获得有效情报，旧剪影不会自动重新出现；历史情报状态按原规则保留，不能宣称本次获得了新情报。

### 自动预瞄

- 有新假 Peek 或换边情报时，下一次真架枪在动作开始时将准星一次性吸附到最后观察位置。
- 自动预瞄消费的是旧位置情报，不读取敌人当前真实位置。
- 换边后应按新站位指向旧情报的同一个世界位置，不复用旧侧屏幕坐标或旧侧瞄准角度；移动期间不吸附。
- 一次吸附后，玩家可以立即通过中央拖动或开火拖动修改准星。
- 真架枪结束后直接再次真架枪，如果期间没有新的有效观察情报，保留上一次手动瞄准方向。
- 新的有效假 Peek 或换边情报会覆盖更早的观察位置，并让下一次真架枪重新执行一次吸附。

## 敌人位置与情报过期

- 战斗模块 V1 提供五个敌人候选位置，用于形成不同的射角和露出比例。
- 五个位置不要求相同遮挡程度，可以包含只露头、露肩、上半身和全身暴露。
- 每次任意 Peek 完全结束、玩家重新完全隐藏后，敌人有 `25%` 概率换到另外四个位置之一。
- 每次完整换边也仅在目标隐藏位完成落位后结算一次同样的 25% 换位；出发、中途暂时不可见均不结算，不重复处理出发前已完成的 Peek。
- 敌人换位发生在玩家看不到真实敌人的阶段，不覆盖玩家已经记录的最后观察位置。
- 因此，黄色剪影和下一次自动预瞄可能正确，也可能已经过期；玩家需要通过再次假 Peek、射击反馈或后续战斗信息修正判断。

## 射击与后坐力

- H5 V1 使用约 `108ms` 的连续射击间隔作为 V1 初始体验参数；后续调整必须经过设计变更流程。
- 第 1 发产生明确起跳；第 2～4 发垂直爬升逐渐增强。
- 从第 5 发开始，角色进入自动稳枪阶段，垂直冲量下降且回正加快。
- 随机水平后坐力贯穿连射全程，使压枪不能退化为完全固定轨迹。
- 玩家在起跳和爬升阶段需要更积极地下压；进入自动稳定阶段后需要减少下压，否则会压过目标。
- 松开开火后，本轮连射阶段结束；下一次按住从首发起跳重新开始。
- 当前 V1 只验证射线方向、命中位置和后坐力手感，不定义伤害、护甲或弹药结算。

## V1 基础状态

| 当前状态 | 玩家输入或事件 | 下一状态 | 主要结果 |
|---|---|---|---|
| 掩体后 | 按住假动作 | 假 Peek 中 | 摄像机持续探出；可以观察并建立情报，不能开火 |
| 假 Peek 中 | 敌人轮廓达到 10% | 假 Peek 中 | 更新最后观察位置并标记“已预瞄” |
| 假 Peek 中 | 松开假动作 | 返回中 | 摄像机开始缩回，真实敌人逐渐消失 |
| 掩体后 | 点击真架枪 | 真架枪探出中 | 自动持续探出；有新情报时一次性预瞄旧位置 |
| 真架枪探出中 | 按住开火 | 真架枪探出中 | 进入预备发射，完全探出前不产生子弹 |
| 真架枪探出中 | 完全探出 | 架枪中 / 连续射击中 | 建立枪线；若已预备则自动开始射击 |
| 架枪中 | 按住 / 松开开火 | 连续射击中 / 架枪中 | 持续射击并产生后坐力 / 立即停火 |
| 架枪中 | 拖动中央画面或开火手指 | 架枪中 | 调整准星并抵消部分后坐力 |
| 架枪中 | 再次点击真架枪 | 返回中 | 停止射击并缩回掩体 |
| 返回中 | 完全隐藏 | 掩体后 | 恢复遮挡；25% 概率触发敌人换位；有效假 Peek 情报生成黄色剪影 |
| 掩体后 | 点击换边 | 换边跑动/抵达中 | 隐藏旧剪影、锁定其他战斗输入，立即开始面向通道横移；实际可见轮廓达到 10% 时更新情报 |
| 换边跑动/抵达中 | 完成目标隐藏位落位 | 另一侧掩体后 | 结算一次 25% 敌人换位；显示本次有效情报剪影；不自动 Peek |

## 核心博弈循环

```text
掩体后观察有限环境
→ 假 Peek 获取或刷新位置情报
→ 缩回后看到最后位置剪影
→ 判断是否相信这份可能过期的情报
→ 真架枪并预瞄旧位置，或再次假 Peek
→ 完全探出后按住开火并调瞄、压枪
→ 返回掩体，敌人可能换位
→ 根据新旧情报进入下一轮
```

这个循环的核心不是比较纯数值，也不是完成一次选择后直接结算，而是在“安全但不能攻击”“低承诺观察”“高承诺架枪”“可能过期的预瞄”之间持续转换。

## 核心术语

| 术语 | V1 定义 |
|---|---|
| 掩体后 | 摄像机和角色处于真实遮挡后，不能射击真实敌人，但可以看到已记录的黄色情报剪影 |
| 假 Peek / 假动作 | 按住时探出、松开即回的观察动作；不能开火，可以获取位置情报 |
| 真架枪 | 点击后自动探出并保持的攻击承诺；完全探出后可以射击 |
| 预备开火 | 真架枪探出过程中已经按住开火；输入被保留，但完全探出前不发射 |
| 最后观察位置 | 最近一次有效假 Peek 或换边观察达到 10% 可见阈值时记录的敌人旧世界位置 |
| 黄色剪影 | 掩体后显示的最后观察位置提示，不是实时透视或真实敌人模型 |
| 自动预瞄 | 下一次真架枪开始时，将准星一次性吸附到尚未消费的最后观察位置 |
| 情报过期 | 敌人已经换位，但剪影和预瞄仍指向旧位置的状态 |
| 换边 | 仅从隐藏位发起，在左右固定石板之间连续移动并回看通道，抵达后不自动 Peek |

## 必须避免的退化行为

- **假动作无代价攻击：** 假 Peek 可以开火，会同时获得观察安全性和攻击收益。
- **实时透视：** 黄色剪影跟随敌人真实位置，会消灭换位和信息差。
- **自动预瞄保证命中：** 系统直接读取敌人新位置，会让假动作、换位和手动修正失去意义。
- **真架枪输入卡顿：** 玩家提前按住开火后，Peek 完成帧出现明显停顿或丢失输入。
- **手动瞄准负担过重：** 调瞄和压枪变成传统移动端 FPS 的持续高精度操作。
- **后坐力完全随机：** 玩家无法通过观察阶段和拖动行为改善射击结果。
- **盲猜循环：** 玩家没有可理解的情报来源，只能随机选择真假 Peek 或开火。

## 后续扩展草案，不属于 V1 基础方向

以下内容来自早期战斗草案，仍保留为后续设计输入，但尚未由当前 H5 V1 验证或批准：

- 双方 `15` 发弹匣、空弹架枪、右下角单次触发 `2s` 换弹和敌方换弹信息隐藏。
- 探身过程中的被攻击概率、伤害、`MISS` 与掉血数字反馈。
- 换边时的受击、暴露命中概率与更多移动战术；双侧固定换边本身已由 008 批准，不再属于未批准草案。
- 手雷破点、趴下架枪、卡壳、伤势、护甲和穿透。
- 机器人在探身、回掩体、架枪、换位和投雷之间的决策。
- 多人同时介入、近距离遭遇和多条枪线。

这些扩展必须分别完成设计、必要的 H5 验证、技术设计和 Unity 实现，不能因为旧原型曾经存在就视为 V1 已确认玩法。

## V1 验收标准

- [ ] 玩家能够只用一只手完成真假 Peek、真架枪、预备开火、连续射击、调瞄和返回掩体。
- [ ] 现行操作中不存在上滑架枪或下滑回撤的必需输入。
- [ ] 真架枪点击后自动探到底并保持；假动作只在按住期间探出，松开即回且不能开火。
- [ ] 真架枪开始后开火键立即可用，探身过程中只预备，完全探出后才产生射击。
- [ ] 假动作看到至少 10% 敌人轮廓后获得位置情报，未达到阈值时不更新。
- [ ] 完全缩回后在最后观察位置显示黄色透视剪影，下一次 Peek 开始时消失。
- [ ] 黄色剪影不跟随敌人真实换位，能够明确表达“可能过期的旧情报”。
- [ ] 玩家完全隐藏后，敌人按 25% 概率在五个不同露出位置间换位。
- [ ] 有新情报时下一次真架枪一次性预瞄旧位置；没有新情报时保留上一次手动准星。
- [ ] 真架枪期间可以拖动中央非按钮区域调瞄，也可以拖动开火手指压枪。
- [ ] 连射具有首发起跳、短暂爬升、角色自动稳枪和随机水平偏移。
- [ ] 默认掩体后只能看到有限通道，Peek 后能感到明确的遮挡变化、纵深和视差。
- [ ] 页面无滚动、浏览器缩放或 iOS 长按选择干扰。
- [ ] 玩家能够解释自己使用假动作、相信或怀疑旧情报、真架枪和修正准星的原因。

### 008 扩展验收

- [ ] 单手可换边，仅隐藏位可发起；连点不排队，移动期间无开火、自动 Peek 或调瞄。
- [ ] 双方向点击后直接横移，全程面朝通道，无预转头/回看/自动追踪；总时长 0.80s，身体/镜头无瞬移与穿模，两侧 Peek 方向和侧倾正确。
- [ ] 横移/抵达仅在轮廓达到 10% 时记情报，落位后无额外观察窗口；有效情报剪影只显示旧世界位置。
- [ ] 换边完整落位仅结算一次 25% 换位；不在敌人可见时触发瞬移，不因中途遮挡重复结算。
- [ ] 跨侧预瞄一次性指向旧世界位置；没有新情报保留手动瞄准方向。
- [ ] 暂停/失焦释放输入并冻结换边，恢复后继续到目标，不积累后台移动或射击。
- [ ] Blender 源文件、导出模型与 Unity 接入一致，无 Unity 独有模型补丁；两侧分别检查五个敌人点位、隐藏/暴露和完整路径。
- [ ] 手机竖屏触达、横移可读性与舒适度通过，普通真假 Peek、开火与压枪无回归。

## 待决策

1. 真架枪再次点击返回的触达、反馈和是否允许在 300ms 探出过程中取消。
2. `10%` 识别阈值、`25%` 换位概率、五个位置分布和剪影持续规则是否需要继续调参。
3. 黄色剪影的强度、轮廓样式和信息栏是否会过度暴露情报。
4. 自动预瞄应指向头部、最后可见轮廓中心还是敌人整体位置。
5. 手动调瞄范围、灵敏度和后坐力强度是否仍满足低操作负担目标。
6. 换边减速与 0.80s 横移的体验调优；弹匣、伤害和手雷模块的后续顺序。008 直接横移规则已批准，体验仍需验证。
7. 敌人 AI 如何利用换位、假动作和架枪状态，而不读取玩家不可见信息。
8. Unity 首个战斗实现切片应只覆盖摄像机与输入，还是同时加入最小射击和敌人状态。
