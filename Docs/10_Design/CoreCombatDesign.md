# 核心战斗设计

## 文档目标

定义 EFTM 如何用竖屏单手操作，还原《逃离塔科夫》枪战中围绕掩体、架枪先手、干拉、换位和投掷物形成的经典博弈。本文件定义玩家可观察规则，不决定完整武器数值、动画实现或网络同步方式。

## 范围

### 包含

- 玩家从掩体内上滑架枪、按住连续开火和下滑主动缩回掩体的基本循环。
- 第三人称视角下，通道尽头敌方掩体与通道近端玩家左右掩体之间的一条有效枪线。
- 先架枪对后暴露目标的优势。
- 已知敌人架枪时，使用手雷、回掩体或换位破局。
- 多个短博弈循环如何组成一次完整交战。
- 竖屏单手输入的最低要求。

### 不包含

- 完整武器、弹药类型、护甲、伤势和穿透数值。
- 无掩体近距离遭遇、室内突入、近战或治疗。
- 多人网络同步和延迟补偿方案。
- 具体 UI 视觉稿、按钮位置和手势参数。

## V1 视角与战场约束

- 游戏采用第三人称视角。
- 敌人位于通道尽头，玩家位于通道近端并可停留在左侧或右侧掩体。
- 敌人完全退入尽头掩体时，其角色模型不可见；玩家只能根据先前交战信息推断其状态。
- 首个原型只存在一条有效枪线，不需要玩家选择方向或目标。
- 当任意一方探身或玩家横穿左右掩体时，角色进入这条枪线；已经完成架枪的一方获得开火机会。
- 手机设计基准分辨率为 `1080 × 2160` 竖屏，所有核心战斗输入和反馈必须在此画幅中成立。

## 探身暴露与反击规则

- 已经完成架枪的角色不需要等待敌人完全探出；敌人一开始从掩体中暴露，就进入有效射击条件。
- 正在探身的角色可以在探身过程中受到伤害，但在完全探出前不能使用枪械反击。
- 以探身暴露进度 `E` 表示角色从掩体内到完全探出的比例，`E` 从 0 变化到 1。
- V1 探身总时长为 300ms。
- 探身开始后的前 150ms，角色虽然已经开始移动，但每发子弹命中该角色的概率为 0%。
- 从第 150ms 起，单发命中概率立即进入 30%，然后随剩余探身时间线性提升，到第 300ms 完全探出时达到 100%。
- 以探身暴露进度 `E` 表示时，`E < 0.5` 的单发命中概率为 0%；`E ≥ 0.5` 时为 `30% + 70% × ((E - 0.5) / 0.5)`。
- 当 `E = 1` 时，角色完成探身、进入架枪状态；玩家获得手动开火按钮，机器人按 AI 射击逻辑行动。
- 完全位于掩体内时不能被普通直射枪火选为目标。

## 切换掩体规则

- 玩家在通道近端拥有左、右两个有效掩体；处于左侧时向右滑、处于右侧时向左滑，即可在两者之间切换。
- V1 切换动作持续 600ms；期间玩家横穿通道，不能架枪、开火或换弹。
- 切换期间敌方每发子弹命中玩家的概率固定为 20%，不沿用普通探身的暴露曲线。
- 切换完成后玩家立即获得新掩体保护，并从新侧重新建立枪线。

## 弹匣与换弹规则

- 双方每个弹匣均包含 15 发子弹；玩家按住开火键时按武器射击间隔连续消耗子弹，松开立即停止。
- V1 中弹匣打空后不会自动回掩体，也不会自动开始换弹。
- 弹匣为空时，角色保持当前架枪和暴露状态，但不能继续攻击；玩家可直接点击右下换弹，也可下滑主动回掩体后再换弹。
- 空弹时主操作区明确提示“返回掩体，子弹夹已空”。
- 弹匣打空瞬间触发一次高优先级视觉与触觉警示；空弹持续期间保留独立警报条，并让当前相关操作按钮进入警示配色。
- 警报指令随状态变化：暴露架枪时提示“右下换弹或下滑回掩体”，回撤时提示准备换弹，完全回掩体后指向右下换弹键。
- 玩家下滑后角色才执行回撤；回撤过程中仍然可以被命中。
- 原有底部左、中、右三枚操作按钮删除；战场区域承载横向切换、上滑架枪和下滑回撤，弹匣及换弹键固定在右下角。
- 当前弹匣未满时，玩家可在完全处于掩体内或已经完成架枪时点击右下换弹；弹匣不必先打空。
- 右下换弹键点击一次即触发换弹，随后自动执行 2 秒；不要求持续按住。
- 探身过渡、回撤与切换掩体期间换弹键不可用。
- 掩体内换弹时保持隐藏和直射保护；架枪后换弹时保持完全探出、100% 被命中概率且不能攻击，完成后回到架枪状态。
- 玩家始终看到自己的剩余弹药和换弹进度。
- 玩家看不到敌方的弹药数量、换弹状态文字或换弹剩余时间；只能根据枪声中断、敌人回掩体和交战历史进行推断。

## 战斗核心定义

一次交战不是选择一次“剪刀、石头或布”后直接结算，而是由多个短循环组成：

```text
观察与判断
→ 选择继续藏身、上滑架枪、横向切换掩体、投雷或回撤
→ 架枪完成后决定是否按住连续开火
→ 一方受伤、回掩体、失去位置或死亡
→ 根据新情报进入下一轮判断
```

玩家不负责准星微操和压枪，但负责按住或松开开火键控制火力持续时间。玩家还负责决定什么时候承担暴露风险、什么时候争夺架枪先手，以及怎样破解对方已经建立的枪线优势。

## 核心术语

| 术语 | 本项目定义 |
|---|---|
| 掩体内 | 角色完全缩在有效掩体之后。无法使用枪械攻击，也不会被普通直射枪火命中。 |
| 探身 | 玩家上滑架枪后，角色歪头从掩体中暴露并开始建立枪线的不可取消过渡过程。 |
| 架枪 | 角色已经歪头探出、面向威胁方向并持续瞄准；玩家此时可以按住中央开火键连续射击。 |
| 先架优势 | 两名角色互相进入可攻击状态时，更早建立稳定枪线的一方更快、更容易命中。 |
| 干拉 | 明知或未确认敌方枪线状态时，直接离开安全掩体进入对方可能覆盖的射界。 |
| 换位架枪 | 放弃已经暴露的位置，移动到新掩体或新射角后重新架枪。 |
| 回掩体 | 玩家在完成架枪后下滑，角色停止攻击并执行缩回掩体的动作。 |
| 破点 | 使用手雷或其他手段迫使已经架枪的敌人取消枪线、回掩体或离开当前位置。 |

## 单手核心输入

### 战场手势：架枪 / 回掩体

- 玩家在战场区域上滑，角色开始从当前掩体歪头探身并建立枪线。
- 松手后动作仍继续；300ms 架枪过程完成前不能通过反向滑动取消。
- 完成架枪后，玩家下滑才开始回撤。
- 回掩体需要表现为角色动作，而不是输入瞬间传送；角色完全回到掩体后才重新获得完整掩体保护。

### 屏幕中央：按住开火

- 只有完成架枪时，屏幕中央才出现独立开火键。
- 玩家按住后按 100ms 实验射击间隔连续开火，松开立即停止。
- 开火不取消架枪，弹匣打空后按钮禁用并进入空弹警示。

### 横向滑动：切换掩体

- 只有完全处于掩体内时可发起切换；左侧向右滑，右侧向左滑。
- 有效滑动后玩家在通道近端左右掩体间横穿 600ms，期间每发被命中概率为 20%。
- 架枪、回撤、切换和换弹期间不能再次发起切换。

### 第二只手

- 第二只手可以提供可选的快捷辅助，但不能影响核心循环是否可玩。
- 玩家必须能够只用一只手完成上滑架枪、按住连续开火、下滑回掩体和横向切换掩体。

## 基础战斗状态

| 当前状态 | 玩家输入或事件 | 下一状态 | 主要后果 |
|---|---|---|---|
| 掩体内 | 上滑 | 探身中 | 歪头开始暴露并建立枪线；松手不撤回，完成前不可取消 |
| 探身中 | 300ms 动作完成 | 架枪中 | 持续瞄准并显示独立开火按钮 |
| 架枪中 | 按住 / 松开中央开火键 | 架枪中 / 连续射击中 | 按射击间隔持续结算 / 立即停止射击，仍保持架枪 |
| 架枪中 | 下滑 | 回撤中 | 停止维持枪线，开始缩回掩体 |
| 架枪中 | 手雷形成有效威胁 | 回撤或换位 | 继续原地架枪将承担高风险 |
| 回撤中 | 完成动作 | 掩体内 | 失去攻击能力，恢复普通直射枪火保护 |
| 架枪中 | 弹匣打空 | 空弹架枪中 | 保持暴露和枪线，但无法攻击；可右下换弹或下滑回掩体 |
| 空弹架枪中 | 下滑 | 回撤中 | 主动回掩体；回撤过程中仍可被命中 |
| 掩体内且弹匣未满 | 点击右下换弹键 | 换弹中（隐藏） | 触发 2 秒自动换弹，保持掩体保护 |
| 架枪中且弹匣未满 | 点击右下换弹键 | 换弹中（暴露） | 触发 2 秒自动换弹，保持 100% 暴露且不能攻击 |
| 换弹中 | 2 秒完成 | 原状态 | 弹匣恢复至 15 发；掩体内恢复隐藏，暴露换弹恢复架枪 |
| 掩体内 | 朝另一侧横向滑动 | 切换掩体中 | 横穿左右掩体 600ms；不能攻击，每发被命中概率固定 20% |
| 切换掩体中 | 600ms 完成 | 掩体内 | 进入另一侧掩体并恢复保护 |
| 任意可行动状态 | 受到致命伤害 | 死亡 | 结束本次交战与出击 |

## 架枪先手规则

1. 架枪优势是一个随时间建立的状态，不是按下按钮立即获得的标签。
2. 先完成探身并架枪的一方，在敌人刚开始暴露时即可立即发起射击；玩家仍需按住开火，机器人由 AI 决定射击。
3. 后探身者在完全探出前不能反击；探身前 150ms 单发命中概率为 0%，后 150ms 从 30% 线性上升到 100%。
4. 后探身者仍可能依靠对方未命中、弹匣打空或主动回撤生还，但常规干拉不应成为对抗已知架枪者的理性最优解。
5. 自动瞄准替代准星微操，但玩家仍负责按住或松开扳机，以及对时机、枪线、弹药和风险的判断。
6. 架枪优势必须可被观察或推断；如果玩家只能无信息猜测对手状态，系统会退化为盲猜。

## 相互克制关系

本系统的“剪刀石头布”是不断变化的情境克制，不是固定三个按钮：

| 战术 | 通常克制 | 通常被克制 | 付出的代价 |
|---|---|---|---|
| 提前架枪 | 对手后续探身、干拉或经过枪线 | 手雷破点、未知方向换位 | 暴露身体、固定注意方向、消耗时间 |
| 缩回掩体 | 敌方普通直射火力 | 手雷、包抄、资源和时间压力 | 无法攻击，可能交出主动权 |
| 手雷破点 | 已知位置的静态架枪者 | 投掷前摇期间被抢先探身、敌人提前换位 | 消耗有限投掷物并暴露意图 |
| 换位架枪 | 对旧位置的预瞄和投掷物 | 移动过程中被发现或截击 | 暂时失去掩体与已有枪线 |
| 抢先探身 / 干拉 | 正在投雷、换位或尚未建立枪线的敌人 | 已经完成架枪的敌人 | 主动暴露并承担死亡风险 |
| 趴下架枪 | 特定射角与稳定性需求 | 手雷、包抄、需要快速回撤的情境 | 机动和回撤能力下降 |

因此，先架枪不是无条件胜利：它压制直接探身，却会暴露位置并给对方使用手雷或换位创造依据。手雷也不是无条件胜利：它消耗资源、存在准备窗口，并可能被对方提前回撤或换位规避。

## 一个典型博弈循环

1. 玩家 A 在掩体内上滑架枪，完成探身并架住通道。
2. 玩家 B 直接探身进入该枪线；A 因先架优势可以立即按住开火，B 受到明显威胁。
3. B 完成架枪后下滑回到掩体，放弃继续干拉。
4. B 根据 A 的已知位置使用手雷破点。
5. A 必须回掩体、换位或承担手雷风险，因此失去原有枪线。
6. B 可以趁 A 处理手雷时争夺新的架枪先手。
7. A 若提前换到新射角，则双方基于新信息进入下一轮循环。

## 必须避免的退化行为

- **架枪后无代价：** 架枪没有暴露、时间或弹药代价，导致所有人永久保持架枪。
- **反向手势取消风险：** 上滑架枪后能在动作完成前立刻下滑撤回，导致试探输入成为无风险最优操作。
- **手雷万能：** 投掷没有资源、准备时间和暴露代价，导致每次遭遇都固定先扔雷。
- **纯装备碾压：** 博弈选择无法抵消任何装备差距，玩家只比较战力。
- **盲猜循环：** 玩家看不到、听不到也无法推断对方状态，只能随机选择行动。
- **动画演出替代决策：** 玩家架枪后长时间观看不可干预的结果，无法选择开火、回掩体或改变方案。

## 战斗文字反馈

- 每次射击未命中时，在被攻击角色附近显示浮动文字 `MISS`。
- 每次射击造成伤害时，在受伤角色附近显示负数形式的实际掉血数值，例如 `-5`。
- 浮动文字只解释本次射击结果，不暴露敌方弹药数量、换弹状态或其他隐藏信息。

## V1 验证切片

- 通道尽头的一处敌方掩体、通道近端的玩家左右掩体和一条主要交战枪线。
- 玩家与一个机器人 PMC。
- 上滑架枪且过程不可取消；架枪完成后显示中央开火键，玩家按住连续开火、松开停止；下滑回掩体。
- 敌人退入尽头掩体后完全不可见；探身后重新进入视野。
- 从左侧向右滑、从右侧向左滑以切换掩体；600ms 横穿期间每发被命中概率固定为 20%。
- 双方 15 发弹匣；打空后保持空弹架枪；弹匣未满时可在掩体内安全换弹，也可在架枪状态下保持完全暴露换弹，均由右下换弹键单次触发 2 秒自动换弹。
- 已架枪者在目标探身过程中开火；300ms 探身的前 150ms 命中概率为 0%，后 150ms 从 30% 提升至 100%。
- 未命中显示 `MISS`，造成伤害显示实际掉血数值。
- 玩家可见自身弹药和换弹进度，但看不到敌方换弹 CD。
- 可观察的先架优势。
- 一种有限手雷，可迫使机器人取消静态架枪或换位。
- 机器人能够在探身、回掩体、架枪、投雷和换位中做出基本选择。
- 一次遭遇能够自然出现至少两个短博弈循环，而不是第一次选择后直接结束。

## 验收标准

- [ ] 玩家只用一只手即可完成核心交战。
- [ ] 玩家一次上滑即可开始架枪，松手不会撤回，且架枪完成前不能反向滑动取消。
- [ ] 架枪完成后中央开火键出现；按住连续射击，松开立即停止。
- [ ] 已经完成架枪的角色对随后干拉的敌人具有显著但非绝对的先手优势。
- [ ] 已架枪角色从目标开始探身时即可射击；探身目标完全暴露前不能反击。
- [ ] 探身总时长为 300ms；前 150ms 每发命中概率为 0%，后 150ms 从 30% 连续提升至 100%。
- [ ] 双方弹匣均为 15 发；打空后保持架枪但不能攻击，不会自动回掩体。
- [ ] 玩家无需持续观察弹量数字，也能立即识别空弹并理解下一步应回掩体或换弹。
- [ ] 底部三枚操作按钮不存在；横向滑动切换、上滑架枪、下滑回撤，中央开火键仅在架枪完成后出现，弹匣与换弹键固定右下。
- [ ] 玩家可在左右掩体间切换；600ms 移动期间不能攻击，敌方每发命中概率固定为 20%。
- [ ] 敌人完全位于通道尽头掩体后时不可见，暴露后才重新显示。
- [ ] 弹匣未满时可在掩体内或架枪状态点击右下换弹键；单次触发后自动执行 2 秒，并正确区分安全换弹与暴露换弹。
- [ ] 玩家与机器人使用相同生命、弹匣、探身、回撤、射击、伤害与换弹参数，差异仅来自决策控制。
- [ ] 未命中显示 `MISS`，命中显示实际掉血数值。
- [ ] 玩家可见自身换弹进度，不能直接看到敌方换弹 CD。
- [ ] 玩家发现敌人已经架枪后，能够通过手雷或换位获得至少一种合理破局路径。
- [ ] 完全回到有效掩体中的角色不会被普通直射枪火命中，同时不能使用枪械攻击。
- [ ] 架枪和回撤存在可感知的动作过程，快速点按不会形成无风险攻击。
- [ ] 玩家能够根据可观察信息解释自己为什么占优、受伤或死亡。
- [ ] 一次典型遭遇包含多个可逆的判断循环。

## 待决策

1. 横向切换、上滑架枪、下滑回掩体、中央按住开火与右下换弹的触达面积和视觉反馈。
2. 探身、稳定架枪、手动开火、回撤和切换掩体的目标时长。
3. 玩家如何获知对方正在架枪、投雷、换位或已经受伤。
4. 手雷如何在单手操作下选择、瞄准和投掷，以及投掷时是否需要探身。
5. 手雷能否直接伤害掩体内角色，还是主要通过危险区迫使其移动。
6. 趴下和更复杂换位由什么单手输入触发。
7. 双方同时架枪、极近距离相遇和多个敌人介入时如何处理。
8. 正式背包与弹匣系统中，换下弹匣的剩余子弹、弹匣保留和重新装填如何处理；当前原型只验证主动换弹手势。
9. 卡壳、压制和伤势在首个原型中保留到什么程度。
