# EFTM H5 原型

本目录用于设计者明确提出的 H5 体感、交互或可用性验证。

H5 原型是可选工具，不是设计评审或 Unity 开发的固定门禁。没有明确的设计者触发、验证假设、范围和判据时，不创建具体原型。

当前状态：工作区已建立，尚未选择前端框架，也没有正在执行的 H5 验证任务。首次原型任务应在这里补充：

- 绑定的工作项和设计来源；
- 验证假设、范围与非目标；
- 本地启动方式；
- 测试和目标视口验证方式；
- 实验产物的保留或清理策略。

工作规则见 [AGENTS.md](AGENTS.md)，跨 agent 交接见 [H5 Prototype Agent](../Docs/00_Project/Agents/H5PrototypeAgent.md)。
