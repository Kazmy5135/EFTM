# EFTM H5 原型

## 当前实验

`H5-PEEK-CAMERA-001`：手机竖屏下的真 3D 掩体摄像机 Peek 体感原型。

- 绑定工作项：`Docs/30_Iterations/004-peek-camera`
- 目标分辨率：1080×2160 竖屏，同时验证 540×1080 等效视口。
- 验证假设：玩家默认退在近墙后，主体视野被遮挡但画面左侧边缘能预先看到一条通道；真架枪点击后自动 Peek 到底并锁定，假动作保持按住探出/松开缩回，二者应形成清晰的承诺与试探差异。
- 技术方案：Three.js WebGL 真 3D 场景，本地 npm 依赖在启动前打包，由现有局域网服务器提供单一浏览器脚本。
- 开火热路径：复用单一 Web Audio 上下文、预生成枪声音频、复用单一弹道线、限定射线碰撞集合，并在 Peek 完成画面渲染后的下一帧结算预备的第一发，避免状态切换帧卡顿。

这是实验实现，不是正式玩法设计、Unity 生产代码或美术标准。场景比例、材质、灯光与摄像机数值均为占位参数。

上一版战斗 H5 已保存在 Git 提交 `de45dd2`，不在本分支的当前实验范围内。

## 运行

需要 Node.js 18 或更高版本：

```powershell
cd H5Prototype
npm install
npm run serve
```

电脑浏览器打开 `http://127.0.0.1:4173/`。服务器会同时输出 `LAN` 地址，同一局域网内的手机直接打开该地址。

Three.js 从本机 `node_modules` 构建进 `peek-app.js`，手机不需要访问外部 CDN，也不需要运行时加载 ES Module。

## 操作

- 默认状态摄像机在右侧近墙后并向后留出距离，通道主体被真实 3D 几何体遮挡，但左侧边缘保留少量通道预览。
- 点击左侧“真架枪”：摄像机用 300ms 横向探到底并锁定；中央 `FIRE` 立即可按住预备，完全探出后自动开始射击；再次点击真架枪缩回。
- 按住右侧“假动作”：保持按住时 Peek，松开后用 240ms 缩回；假动作不能开火。
- 按住圆形 `FIRE`：完全探出后约每 108ms 从屏幕中央准星发出一发。第 1 发正常起跳，第 2～4 发逐发加剧，第 5 发起角色自动稳枪，垂直冲量降至基础值的 52% 且回正加快；随机左右偏移始终存在。按住手指可向任意方向拖动镜头，初段需要明显向下压，稳定后必须减小下压避免压过头，松开立即停火并让下次连射重新进入起跳段。
- 桌面调试：`E` 切换真架枪，按住空格模拟假动作，`F` 开火。

本实验只有固定假人和单发射线反馈，没有敌人 AI、伤害、生命、弹匣、换弹或切换掩体。

## 检查

```powershell
npm run check
```

检查包含真架枪/假动作状态模型、摄像机恢复、准星射线与固定假人场景契约、手机竖屏、iOS 手势抑制、本地 Three.js 模块和局域网服务器契约。

视觉验证辅助地址：`/?debugPeek=1` 会保持假动作完全探出；`/?debugAim=1` 会保持真架枪完全探出并显示开火键。两者仅用于构图检查，不代表正式输入方式。
