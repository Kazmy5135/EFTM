# EFTM H5 原型

## 当前实验

`H5-COMBAT-001`：第三人称单枪线掩体战斗体感原型。

- 绑定工作项：`Docs/30_Iterations/003-core-combat`
- 设计来源：`DESIGN-CORE-COMBAT`（draft）
- 验证交接：`Docs/30_Iterations/003-core-combat/H5PrototypeBrief.md`
- 目标分辨率：1080×2160 竖屏；同时验证 540×1080 @2x 等效视口。
- 核心输入：战场区域横向滑动切换掩体、上滑歪头架枪、下滑回掩体；架枪完成后按住中央开火键连续射击。

本目录是实验实现，不是正式设计或 Unity 生产代码。当前数值、AI、美术和反馈均为占位内容。

## 运行

需要 Node.js 18 或更高版本：

```powershell
cd H5Prototype
npm run serve
```

电脑浏览器打开 `http://127.0.0.1:4173/`。

服务器默认监听局域网接口，并在启动时输出 `LAN` 地址。同一局域网内的手机直接打开该地址，例如当前开发机为：

```text
http://172.16.1.40:4173/
```

如果 Windows 首次弹出网络访问提示，只允许“专用网络”即可；不要开放公用网络。电脑或手机切换网络后，重新启动服务器并使用新输出的 `LAN` 地址。

也可以直接打开 `index.html`，但本地服务器更接近手机浏览器行为。

## 操作

- 敌人位于通道尽头；完全退入尽头掩体时角色不可见，探身后才进入玩家视野。
- 原有底部三枚操作按钮已经删除；战场区域承载核心手势，弹匣与换弹键固定在右下角。
- 在战场区域上滑即开始 300ms 歪头探身架枪；松手不会撤回，架枪完成前也不能取消。
- 完成架枪后屏幕中央出现独立开火键；按住连续开火，松开停止，角色继续保持架枪。
- 架枪完成后下滑，角色主动回到当前掩体。
- 位于左侧掩体时向右滑、位于右侧掩体时向左滑，即可切换掩体；移动耗时 600ms，期间敌方每发子弹固定有 20% 命中概率。
- 双方弹匣均为 15 发。弹匣打空时角色保持架枪但无法攻击，可点击右下换弹或下滑回掩体。
- 弹匣打空瞬间触发红色屏幕边缘闪烁与双段振动；随后持续显示“弹匣已空”警报条，并让中央开火键与换弹键进入高对比脉冲状态。
- 只要弹匣未满，完全藏好或完成架枪后都可点击右下换弹键，随后自动执行 2 秒换弹。
- 掩体内换弹保持安全；架枪换弹保持 100% 暴露、期间不能攻击，完成后恢复架枪。探身、回撤或切换期间不能换弹。
- 探身总时长为 300ms：前 150ms 单发命中概率为 0%；从 150ms 起由 30% 线性提升至完全探出时的 100%。
- 未命中时在目标位置显示 `MISS`，命中时显示实际掉血数字。
- 玩家可见自己的剩余弹药和换弹进度，但看不到敌方换弹倒计时。
- iOS 长按放大镜、触控菜单、文字选择、双击缩放和双指缩放均已禁用。
- 核心手势与按住开火均保留 iOS 浏览器默认手势抑制。
- 桌面调试可用 `↑` 架枪、`↓` 回掩体、按住 `F` 连续开火、`Q` 切换掩体。
- 点击右上角“重置”重新开始。

## 检查

```powershell
npm run check
```

检查包括 JavaScript 语法、核心战斗状态模型、弹匣换弹、页面信息隐藏与局域网服务器契约测试。

## 覆盖与非目标

当前只覆盖一名玩家、一名机器人、通道尽头敌方掩体、玩家左右掩体和单一枪线。手雷、趴下、多目标、正式数值、联网与 Unity 性能均不在本原型范围。
