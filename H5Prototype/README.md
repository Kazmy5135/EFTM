# EFTM H5 原型

## 当前实验

`H5-PEEK-CAMERA-001`：手机竖屏下的真 3D 掩体摄像机 Peek 体感原型。

- 绑定工作项：`Docs/30_Iterations/004-peek-camera`
- 目标分辨率：1080×2160 竖屏，同时验证 540×1080 等效视口。
- 验证假设：玩家默认被近处墙体完全遮挡，看不到通道；按住 `PEEK` 后摄像机横移并侧倾，逐渐露出通道纵深；松开后立即开始缩回。
- 技术方案：Three.js WebGL 真 3D 场景，本地 npm 依赖在启动前打包，由现有局域网服务器提供单一浏览器脚本。

这是实验实现，不是正式玩法设计、Unity 生产代码或美术标准。场景比例、材质、灯光与摄像机数值均为占位参数。

上一版战斗 H5 已保存在 Git 提交 `de45dd2`，不在本分支的当前实验范围内。

## 运行

需要 Node.js 18 或更高版本：

```powershell
cd H5Prototype
npm install
npm run serve
```

电脑浏览器打开 `http://127.0.0.1:4173/`。服务器会同时输出 `LAN` 地址，同一局域网内的手机直接打开该地址。

Three.js 从本机 `node_modules` 构建进 `peek-app.js`，手机不需要访问外部 CDN，也不需要运行时加载 ES Module。

## 操作

- 默认状态摄像机在右侧近墙后，通道被真实 3D 几何体遮挡。
- 按住底部 `PEEK`：摄像机用 300ms 横向探出并产生约 7° 侧倾。
- 保持按住：保持完全探头，可观察通道纵深。
- 松开：摄像机用 240ms 缩回墙后。
- 桌面调试可按住空格键代替触屏按钮。

本实验没有敌人、开火、伤害、弹匣、换弹或切换掩体。

## 检查

```powershell
npm run check
```

检查包含摄像机状态模型、按住/松开恢复、3D 场景契约、手机竖屏、iOS 手势抑制、本地 Three.js 模块和局域网服务器契约。

视觉验证辅助地址：`/?debugPeek=1` 会保持完全探出，仅用于检查通道构图，不代表正式输入方式。
